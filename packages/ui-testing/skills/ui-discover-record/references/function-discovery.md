# 按功能探索与定位复用

本说明补充现有 discover-record，不增加阶段、工具或批准路径。公开字段以 CLI schema 和实际 MCP tool schema 为准。

## 范围与预算

开始前冻结 scope 中的角色、来源、允许动作及工具预算；录制时间/动作/无进展上限沿用 start 的 max_duration_ms/max_steps/max_no_progress。完成条件是选定功能和断言都有证据或明确缺口，不是“页面都点过”。已存在有效资产时只核对本次相关范围；不能为减少探索次数删掉原范围。

先做一次页面概览，列出入口、共享控件和可见功能。需求/源码中存在但当前角色不可见的功能仍登记为未探索或阻塞，不能因快照中没有就认定不存在。不同角色分别使用匹配其范围的清单和 context，不把另一角色的观察写进当前角色的已验证记录。

## 一次推进一个功能

按范围内优先级选功能，完成它的必要状态后再切换下一个功能。例如查询→清空/重置、弹窗打开→取消/保存、标签→展开、分页→边界、加载→空/错误；这些是风险选择示例，不要求无关页面都具备这些交互。

同一角色和初态允许时沿用当前 recording/session，不重复 setup 或为每个控件回到首页。每次变更状态后检查实际快照，复用明确仍适用的定位；计量 setup、导航、返回和 snapshot 的真实次数。定位失效时先核对当前状态，不靠反复导航或强制点击解决。

一个功能已有来源、状态观察和可复用步骤时，立即通过 inventory 操作保存新清单及 drafts，不等其他功能。草稿可以先是带来源的方案或脚本；drafts 的 name/content 字段可保存该功能的 `.md` 证据说明或 `.ts` 草稿，返回的 draft_refs 即交接依据。保留先前不可变清单；新增观察用新的 inventory ID，稳定 module_id/feature_id/scenario_id 不随页面顺序变化。

复用 inventory 的 entry、role、states、source_refs、source_locations、coverage 和 gaps：源码与真实 observation_ref 分开关联。用 evidence 草稿记录功能/场景→状态/观察→定位→断言来源→脚本的映射，无需扩展 schema 或维护第二份定位器数据库。临时 ref 只用于当前 action，不能写进可复用草稿。

## 定位复用的证据边界

已发现可选 browser_generate_locator 时，通过 action 传当前快照元素的 target，保存实际返回的 locator 及 observation_ref，再将该字符串用作 browser_type/browser_click 的 target 做严格交互核验。不同快照或同页面重载后复用仍须成功交互；生成失败不猜输出，也不把该可选能力升级为所有任务的必需前置。

优先使用原生日志中的 role/label/稳定测试属性定位，将重复定位收敛到同修订的局部变量或已有 helper。重复按钮应限定 dialog、表单、列表行或 frame；不要用 first/nth 掩盖未解释的多匹配。动态列表应按业务对象定位，不能固定临时行号。

“页面上看见一个目标”和“脚本定位唯一且可操作”分开记录。可复用 Playwright locator 要在对应角色/状态核对 count=1，并按交互检查可见/启用或原生 trial；实际成功的严格交互可作为该操作的证据。当前 MCP 不支持的检查不得编造参数或回执；不能核验时标为待核验，留待候选脚本的受控设计诊断，不能提前填稳定定位已通过。定位检查不能替代业务断言。

页面、角色、frame、配置、依赖或部署变化时重验受影响定位；未确认兼容时保留缺口。旧快照、旧清单或源码推测不能标为本轮浏览器证据。源码-only 保持 discovery=source、coverage=discovered，定位全部未核验，不启动浏览器补齐“已探索”。

## 草稿与最终交接

预期来自已登记需求、声明或明确标记的行为基线，观察到的值只证明实际行为。合并公共步骤可复用 helper，但原场景、权限、边界、数据一致性和断言覆盖不能丢失；未知规则留 gap。

generator_write_test 只写本 session 声明的全新 output_file，不能为了逐功能产出而覆盖文件或绕过原录制门禁。阶段性功能草稿用 inventory.drafts；最终脚本关联各功能，完整候选仍走现行设计/评估/诊断。若需独立交付某功能，应在开始前冻结其范围，不能失败后拆分来掩盖原目标缺口。

到达预算、遇到未知副作用或无法核验时，保存已发现/探索/阻塞功能、状态观察及尚未覆盖点，按原流程关闭浏览器并核对归属清理。范围外保留 unexplored；范围内缺口同时保留在功能 gaps 和 finish.gaps，返回 partial，不删 gap 换完整状态。该说明不授予业务写入、入库、绑定或正式执行权限。
