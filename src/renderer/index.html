      技能 · Skills

        MCP 服务器

        连接外部工具服务。这里显示当前对话的真实连接与工具；已安装资源包不等于服务已连接。

          添加 MCP 服务器

          支持 HTTP 和本地 stdio；保存到用户级 mcp.json。仅添加你信任的服务，凭据不会从已保存配置回显。

          安装资源包或导入技能
