# AQA 高保真 Demo

打开 `index.html`，即可在浏览器预览。推荐使用 Google Chrome。

## 文件

- `index.html`：可独立打开的 Demo，固定使用浅色主题。
- `aqa-prototype.fragment.html`：可编辑的原型源文件，后续设计调整以此为准，调整后需同步导出 `index.html`。
- `aqa-desktop.png`：Google Chrome 中的桌面预览截图。

## 体验方式

顶部可切换模型配置、新建会话、写入确认、任务完成四个页面。新建会话中选择示例任务并发送，可进入模拟执行流程。写入确认支持展开全部内容、允许写入、拒绝和停止。

原型使用模拟消息、模型和文件，不连接 DeepSeek、不读取或写入工作目录文件。目录选择、连接检查及 Finder 定位仅展示交互反馈。不要输入真实凭证。

## 已完成验证

2026-10-19，使用本机 Google Chrome 自动化验证：

- 展开文件内容、允许写入、拒绝写入、停止任务后不再进入待确认状态。
- 模拟连接检查与保存后进入新建会话。
- 系统浅色及深色偏好下，应用窗口均保持白色背景。
- 1024、736、375、320px 浏览器窗口宽度下，原型无横向溢出。
- 检查期间无页面脚本运行错误；已人工查看桌面截图。

验证方式为 Google Chrome 自动化，不是 Chrome 扩展。本稿仍为设计原型，不代表正式产品功能已经实现。
