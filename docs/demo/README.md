用 Google Chrome 打开 `index.html`。所有文件、Agent、命令、Git、插件和连接均为模拟，不需要安装依赖、提供凭据或启动服务。

## 推荐评审路线

1. 首页“批准计划” → 查看测试草稿 → “允许写入”或“拒绝”。
2. 允许写入后打开成果 → “运行验证” → 确认模拟命令 → 在底部查看日志，切换 ai-bash / zsh。
3. 右侧“变更” → 查看 Diff → 选择文件暂存 → 输入提交说明 → 模拟提交。未暂存的文件继续保留变更。
4. 点左侧文件 → 编辑 → 切换文件再回来，检查未保存草稿 → 保存到原型内存。
5. 会话列表旁“+” → 输入任务或选模板 → 回答范围问卷 → 审批计划；可停止、创建分支、切换会话。
6. 输入框旁网页拾取图标 → 选择示例登录按钮 → 将选择器加入任务上下文。
7. 打开“Agent 协作” → 委派任务 → 查看分析结果或停止执行者。
8. 打开“插件中心” → 搜索/筛选 → 查看权限 → 模拟启用或停用。
9. 顶栏项目菜单 → SSH 或沙盒 → 查看环境标识变化。此处仅切换环境展示，不生成独立项目数据或连接服务器。
10. 设置 → 检查模拟连接、保存配置；右侧可收起，窄窗口左上角可展开导航。

支持 `/new` 与 `/compact` 的简单示例；Enter 发送、Shift+Enter 换行、编辑器 Cmd/Ctrl+S 保存；活动任务中 Enter 不会误触停止。

## 演示边界

- 原型文件修改仅保留在内存，刷新后重置；不会修改本机项目文件。
- 终端为固定输出，不解释或执行输入的命令；示例 `1 passed / 2 pending` 明确标为模拟，不证明草稿已经通过测试。
- 会话可切换并保留状态，未实现真实模型并发或完整消息历史；任务示例围绕登录场景，不提供任意任务推理。
- 多根目录、队列撤回、多媒体、Git 分支/Pull、真实压缩、真实 SSH、插件运行时与后台自动编排属于产品路线，当前只覆盖部分入口或未提供互动。
- 沙盒/SSH 页面仅演示配置与环境标识；不会复制或读写远程文件。
- 插件是设计示例，没有下载代码，也未验证与 pi-web-ui 插件兼容。
- Page Picker 在示例网页中选取元素，不调用真实浏览器扩展。
- 原型的只读 Key 是占位内容，请勿输入真实凭据。

## 已完成验证

2026-10-19，使用本机 Google Chrome 自动化验证，并人工查看四张桌面截图：

- 结构化提问、计划批准、写入允许/拒绝、停止。
- 文件编辑草稿跨文件保留、内存保存与预览同步。
- 终端模拟执行、取消计时任务后不再输出成功、标签切换。
- 空暂存/空提交说明时禁用提交；仅所选暂存文件变为已提交。
- 会话切换、分支不重放操作；Page Picker 选取与上下文添加。
- 模拟上下文压缩、协作委派/停止、插件搜索/分类/启停。
- 设置检查、SSH/沙盒环境切换。
- 系统浅色/深色偏好下均保持浅色。
- 四个主页面在 1440、1024、736、375、320px 共 20 种页面/宽度组合下无横向溢出；检查期间无页面脚本错误。

这份结果只验证原型交互，不替代后续 SDK、真实文件、命令进程、权限和 macOS 安装包验收。
