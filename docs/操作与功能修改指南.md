## 2. 按功能操作

| 功能 | 操作 | 当前行为 |
|---|---|---|
| 启动 | 打开客户端 | 直接新建对话并聚焦输入框；无需选目录，使用应用数据目录中的专用 `workspace/` |
| 选择工作区 | 输入框上方选择本地目录 | 原生选择器，新建会话并保留未发送内容；取消不改变对话，需要时询问项目信任；运行中不可切换 |
| 配置模型 | 左下模型配置，填写 provider、API 地址、model ID、API Key | OpenAI 兼容表单；其他协议和既有 OAuth 使用 Pi 原配置 |
| 思考能力 | 模型配置中勾选「此模型支持可调思考强度」，保存并加载 | 更新该模型 `reasoning`；必须符合供应商实际能力，不按名称猜测 |
| 思考强度 | 输入栏模型旁下拉框 | Pi SDK 支持的级别；无能力仅显示关闭并禁用。运行中不能切换 |
| 工作区权限 | 输入栏权限入口选择三档 | 当前会话生效并保存；默认工作区读写，运行中不能切换 |
| 发送 | Enter 或右下发送按钮 | Shift+Enter 换行；中文输入法确认候选字、长按 Enter 不误发 |
| 运行中输入 | 可以继续编辑草稿 | Enter 不重复发送、不停止任务；停止使用右下停止按钮 |
| 思考展示 | 点击思考过程标题 | 默认弱化斜体展示，与 Pi 官方 TUI 层级一致；刷新保留展开/收起状态 |
| 执行动画 | 发送任务后自动显示 | Pi 风格点阵转子；仅运行时展示，完成/停止后移除，支持减少动态效果 |
| 工具结果 | 展开工具卡片 | 中文轮次、常见工具名称与状态，展开显示原始标识、输入参数、输出和真实权限拒绝结果；停止不重复显示英文中止错误 |
| 附件 | 输入栏附件按钮 | 图片作为模型附件；普通文件以路径引用供工具读取 |
| 提示模板 | 附件旁模板按钮 | 选择 Pi 声明式模板，发送时展开位置参数/默认值/切片 |
| 扩展管理 | 左栏「扩展能力」 | Packages 安装（可直接粘贴 pi install 命令）/更新/移除及扩展开关，Skills 来源/导入/启停，MCP Servers 当前会话连接与管理；资源包/技能变更新建对话加载 |
| `/` 候选菜单 | 输入 `/`，继续输入筛选；↑↓ 选择、Tab/Enter 补全、Esc 收起，也可点击 | 来自当前会话的命令/Skill/模板；MCP 子命令和服务名沿用扩展参数补全，完整命令 Enter 发送，补全保留后缀和草稿 |
| Skill 调用 | 输入 `/skill:名称 任务` | 正文真实进入模型上下文，聊天仅显示名称和任务；内置工具可只读访问 Skill 资源 |
| Pi 扩展 | 放入用户 `extensions/` 或受信任项目 `.pi/extensions/`，重启后加载；输入 `/命令 参数` | SDK 运行器执行工具、命令、钩子与生命周期；错误显示在会话中，详见 [扩展使用指南](Pi扩展使用指南.md) |
| MCP / Postman | 扩展能力 → MCP 服务器，或 `/mcp` 命令 | 添加 HTTP/stdio、查看真实状态/工具、启停、工具使用方式、登录/退出、重连、移除文件配置；来源及保存范围明确标示 |
| 新建/续接 | 左侧新建或打开历史 | 独立会话；打开不重放工具；历史项目也可继续新建 |
| 重命名 | 会话右侧「…」→ 保存名称 | 1–120 字符单行文本；空会话首次发送后才落盘 |
| 分支续聊 | 会话管理 → 创建分支并打开 | 复制当前已保存进度；原任务不中断，未完成回复不复制，工具不重放 |
| 删除 | 会话管理 → 删除 → 再次确认 | 先停止任务并等待收尾，移除该历史和草稿，保留项目文件和其他分支 |
| 会话栏折叠 | 聊天区左上角按钮 | 收起后释放聊天空间，再次点击展开；条目单行显示，长标题省略，悬停查看完整信息；「最近会话」可独立折叠，搜索会自动展开 |
| 搜索 | 左栏顶部搜索按钮；⌘/Ctrl+K 展开侧栏及搜索框 | 会话名称和项目路径过滤，不是正文全文搜索 |
| 详细信息 | 聊天区右上按钮 | 默认收起的会话信息侧栏 |
| 退出 | 关闭窗口/应用菜单 | 有草稿或运行任务时询问；取消保留任务与窗口 |

快捷键：⌘/Ctrl+N 新建、⌘/Ctrl+K 搜索、⌘/Ctrl+, 模型配置。弹窗打开时不执行后台快捷键；Escape 关闭弹窗或浮层。

当前会话扩展注册的组合键及功能键会通过受校验的 IPC 在主进程执行；客户端保留键优先，输入法确认与长按重复不执行扩展。终端 UI 组件仍不由桌面快捷键自动实现，详见扩展使用指南。

## 3. 工作区权限的实际范围

| 档位 | 文件工具 | 命令 |
|---|---|---|
| 只读 | 只读项目与已加载 Skill 资源，拒绝 write/edit | macOS 沙箱允许读取项目、已加载 Skill 和系统运行文件，禁止文件写入（标准空设备除外） |
| 工作区读写（默认） | 写入限项目内，读取额外允许已加载 Skill 目录；检查真实路径及链接 | macOS 沙箱限制写入项目内，读取项目、已加载 Skill 和系统运行文件 |
| 完全访问 | Pi 原生文件工具，沿用系统账号权限 | Pi 原生命令工具，沿用系统账号权限 |

受限模式的文件内容 I/O 也在沙箱进程执行；不只在执行前做字符串前缀校验。路径检查考虑 `/var` 与 `/private/var` 别名、新建文件的父目录、`..`、符号链接及多硬链接文件的直接修改。

此入口控制 Agent 文件工具与命令的文件范围，**不限制网络**；模型请求、历史保存、用户主动选择的图片附件等客户端自身操作不属于只读工具限制。区外普通文件附件不会自动扩展权限，请先移入项目或明确选择完全访问。

Pi 扩展代码及其自定义工具在主进程以系统账号权限执行，不受上述内置工具文件沙箱隔离；仅加载可信扩展。扩展通过 `ctx.executeTool()` 调用客户端内置工具时仍执行对应工具权限检查。

当前系统实现为 macOS `sandbox-exec`。其他系统的受限文件/命令操作会明确拒绝，不静默退回无限制执行。项目信任仍只控制 Pi 资源；Electron renderer 沙箱仍只隔离界面，三者职责不同。

命令需要读取系统运行目录（如 `/System`、`/usr`、`/Library`、`/opt/homebrew`、系统配置及设备）；这不是完全阻止区外读取的保密环境。现有跨边界硬链接、外部进程同时修改文件等对抗性文件系统场景，不作为完整隔离保证；文件工具会拒绝直接修改多硬链接文件。

权限存于 Pi JSONL 自定义条目 `pi-agent-client:workspace-permission`，随该会话和同项目分支恢复。旧会话没有条目时使用工作区读写。新会话不继承其他会话的完全访问。

## 6. 配置、思考强度和数据

数据默认 `~/.pi/agent`，支持 `PI_CODING_AGENT_DIR`。`models.json` 保存模型定义和 `reasoning`，`auth.json` 保存认证并使用 0600，`settings.json` 提供默认模型/思考，`sessions/` 保存 Pi JSONL。

表单只接受有效 JSON 配置；已有 JSONC 或无效配置报错并保留原文件。API Key 不返回 renderer，也不进入模型定义、历史、日志或文档。仅在用户填写表单时将新输入发给主进程。

打开会话优先选择历史模型，否则使用 Pi 默认配置；目标不可用时沿用已有逻辑回退到首个可用模型。**配置弹窗填写过模型，不等于当前会话已选中它**，以输入栏当前选择为准。

思考能力按 `reasoning` 和 SDK 模型能力表生成选项；不把所有模型强行开放同样级别。选择后赋给真实 Agent，SDK 按供应商协议映射请求参数（如 `reasoning_effort` / thinking 配置）。不支持的级别被拒绝；切到不支持的模型时恢复关闭思考。历史保留思考级别，重启恢复时再次按当前模型能力校验。

Pi Agent 是客户端名称；当前 provider/model ID 跟随请求更新，配置标识或模型自述不能证明服务端模型来源。跨会话草稿只在内存保存，不承诺退出恢复。
